# Jorrob Projects

PWA personale per organizzare progetti portati avanti con ChatGPT.

## Versione
1.0.0

## Sezioni
- Progetti
- Inbox
- Richiesta
- Review
- Versioni

## Principio
ChatGPT resta il punto centrale. Jorrob Projects conserva stato, versioni, problemi, decisioni e prepara richieste ordinate da copiare/condividere in chat.

## Privacy
I dati restano nel browser tramite localStorage. Nessun dato viene inviato automaticamente a ChatGPT o a servizi esterni.
